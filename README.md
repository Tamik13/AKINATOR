# AKINATOR

В этом репозитории содержится исходный код Акинатора - игры в которой отвечая на вопросы да/нет можно отгадать какого либо персонажа или добавить нового

## Использование

Для запуска нужно вызвать в терминале команду

```
build/rls_compile
```

После запуска в терминале, а также голосом Акинатор спросит вас, какую команду исполнить.

```
Чего желаете, сударь?
1)Отгадать
2)Показать дерево
3)Дать определение
4)Выйти с сохранением
5)Выйти без сохранения
```
|Номер|Режим|Описание|
|-|-|-|
|1|Отгадать|В этом режиме вы можете отвечая на вопросы да/нет отгадать персонажа или добавить своего|
|2|Показать дерево|Откроется браузер с svg картинкой дерева персонажей|
|3|Дать определение|Программа выведет описание указанного вами объекта|
|4|Выйти с сохранением|Обновляет базу данных и завершает работу|
|5|Выйти без сохранения|Завершает работу программы|

## Структура проекта

В основе Акинатора лежит [бинарное дерево](https://github.com/Tamik13/bin_tree), хранящее строки.
При запуске он считывает из базы данных постфиксную запись дерева, при выходе можно выбрать - обновить базу данных или нет.
Далее программа выполняет указания пользователя, пока он не захочет выйти.
